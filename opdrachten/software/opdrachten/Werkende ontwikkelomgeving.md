### Stappen
- [Installeer Visual Studio Code, inclusief workspace, folder en helloworld programma](https://github.com/HU-TI-DEV/TI-S2/blob/main/software/inrichten-ontwikkelomgeving/visualstudiocode.md).
- Laat zien dat je een helloworld programma op 2 manieren kunt runnen:
  - vanuit Visual Studio Code met het driehoekje of via Menu, Run, Run Without Debugging
  - vanuit de Terminal
  
## Opleveren
1. Lever het volgende in:
   - een screenshot van je werkende ontwikkelomgeving;
   - het C++ programma voor helloworld (een .cpp bestand).
2. Pas als je bovenstaande hebt ingeleverd, kun je de studentassistent of docent je opdracht laten aftekenen:
Je kunt een HelloWorld programma in C++ runnen
   - vanuit Visual Studio Code en
   - vanuit de Terminal (command line).

### Gebruik van AI
Voor deze opdracht mag je **wel** generatieve AI gebruiken.

### Criteria
- Je hebt Visual Studio Code geïnstalleerd
- Je hebt een Workspace, Folder en HelloWorld.cpp aangemaakt
- Je kunt je code op twee manieren runnen (via de VScode GUI en via de Terminal)

Bij deze opdracht willen we dat je computeromgeving gereed is om code te gaan schrijven. Wij verwachten dat je de code kunt laten runnen tijdens het aftekenen bij de docent.

### Wat in te leveren
- een screenshot van je werkende ontwikkelomgeving;
- het C++ programma voor helloworld (een .cpp bestand).
